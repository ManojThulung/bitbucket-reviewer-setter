Privacy Policy

Reviewer Groups for Bitbucket — Chrome extension

Last updated: November 22, 2026

In short

  • Everything the extension saves stays in your own browser.
  • Nothing is sent to the developer or to any third party.
  • No analytics, no tracking, no ads, and no accounts.

What the extension does

Reviewer Groups for Bitbucket lets you save groups of pull request reviewers and apply a group to a pull request on bitbucket.org in one click, replacing the repository's default reviewers. It only runs on bitbucket.org pages.

Information stored on your device

The extension uses Chrome's local extension storage (chrome.storage.local). This data lives only in your browser profile on your computer. It is not synced to other devices and is never transmitted to the developer.

WhatWhy
Reviewer groups you create: each group's name, and for each reviewer you add, their display name, Bitbucket account ID and profile picture address To show your groups and add those people as reviewers
Which group is currently selected So the right group is applied
Your auto-apply setting (on or off) To apply your group automatically when you open a new pull request, if you turned it on
The workspace and repository name (for example team/project) where you last applied each group To pre-select the same group next time you open a pull request in that repository

Reviewer details are saved only when you choose to add someone by clicking + Add in Bitbucket's own reviewer search.

Information read on Bitbucket pages

To do its job, the extension reads parts of the Bitbucket page you're viewing: the reviewers currently on the pull request, the reviewer search box and its results, and the page address (to recognise pull request pages and the repository name). When you search for a reviewer, it also reads the search results Bitbucket's page has already received, so it can capture the details of a person you choose to save. This happens inside your browser only. The extension doesn't read your code, pull request content, comments, or any other Bitbucket data, and it doesn't record your browsing.

Network requests

The extension makes no network requests of its own and has no server. The only time it loads anything is when the popup shows a saved reviewer's profile picture: the image is loaded from the address Bitbucket provided (Atlassian's servers), exactly as Bitbucket itself loads it. If the picture can't be loaded, a coloured initial is shown instead.

Sharing and selling

The developer doesn't collect your data, so there is nothing to share or sell. No data is transferred to third parties, used for advertising, used to determine creditworthiness, or used for any purpose unrelated to the extension's single purpose described above.

The use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

  • Storage — to save your groups and settings locally, as described above.
  • Access to bitbucket.org — to show the Apply and Remove all controls on pull request pages and to add or remove reviewers there for you.

Deleting your data

You can delete a group or clear a group's reviewers at any time from the extension's popup. Removing the extension from Chrome deletes everything it has stored.

Children

The extension is a developer tool and is not directed at children.

Changes to this policy

If the extension's handling of data changes, this page will be updated and the date at the top will change. The full history is available in the project's public repository.
